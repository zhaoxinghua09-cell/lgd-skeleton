# 逆向分析（受控子骨架）

## 触发条件
当用户提出"分析 / 复刻某功能机理"，且目标为**自有或已获明确书面授权**的项目时加载本技能。

## 输出契约（吸收 REA 的"证据 + 未知"）
每个结论必须附带：原始指令、调用者、相关常量、以及**未能解析的部分**。不交付仅含散文的结论——把"原文音频 + 译文"一起给下游。

## 权属与合规（G16 前置）
- 仅处理你拥有或已获书面授权的目标。
- 不得对第三方生产系统做未获授权的逆向分析。
- 输出的实现版本若借鉴了受保护逻辑，须标注并提示合规闸门。
- 本骨架只做编排与证据归集；重活交给用户自备的反编译/分析引擎（Ghidra / Hopper / IDA 等）。

## 步骤
1. 确认目标权属（自有 / 已授权），未确认不得开工。
2. 调用用户自备的分析引擎，收集指令级证据。
3. 按"输出契约"整理证据与未知。
4. 结果中的密钥 / 凭据不得落库（G3）。

## 验证
